## 👨‍💻 关于我 (About Me)

你好，我是**空太** (KongTai)，一个热爱 Minecraft **1.7.10** 版本的神秘时代（Thaumcraft）模组魔改玩家与开发者。

- 🔭 **目前正在维护：**
  - 🐉 龙之研究修复版 (Draconic-Evolution-KongTai)
  - 🌿 自然魔法分支 (MagiaNaturalis-KongTai)
  - 🌸 植物魔法附属 (ExtraBotany-GTNH)
- ⚙️ **技术方向：** 专注于 GTNH 整合包及 RFG 环境下的模组移植、修复与魔改。
- 🎮 **游戏哲学：** 致力于为玩家提供更平衡、更丰富且充满探索感的神秘时代与生存体验。
- 💬 **联系方式：** 欢迎与我交流模组开发与魔改心得！
  - 🐧 **QQ:** `2897626982`
